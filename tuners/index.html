チューナー動作確認一覧

手元で開発・保有しているテレビチューナーの、Windows（TVTest）と Linux（Mirakurun・KonomiTV）での動作確認の一覧です。

最終更新：2026-11-24

絞り込み
  • ◎視聴TVTest・KonomiTV で視聴を確認
  • ○対応使えるドライバー・ツールがある
  • 調査中解析・入手の途中
機種 放送波 Windows Linux B-CAS

表の見方

Windows
TVTest などの BonDriver で使えるかどうか。Mirakurun で動く機種は、BonDriver_Mirakurun 経由でも使えるため「対応」としています。
Linux
Mirakurun などの録画コマンドで使えるかどうか。KonomiTV で視聴まで確認した機種は「視聴」です。
B-CAS
カードを挿す場所。「外付けも可」は、PC/SC のカードリーダーでも復号できる機種です。
確認日
最後に動作を確かめた日。他の方のドライバーで、手元で試していないものは「未確認」です。
事前準備
ファームウェアの配置やドライバーの割り当てなど、使う前に必要な作業があるかどうか。手順は各リポジトリの README にあります。
